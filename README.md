# 共감 신문 · 세상과 공감하는 우리

초등학교 6학년이 매일 한 편의 글을 읽고 6문제로 이해를 확인하는 문해력 신문이에요.

- **읽기:** 문단 번호, 낱말 뜻 보기, 형광펜 밑줄, 글자 크기, 소리로 듣기, 읽은 시간
- **문제:** 4지선다·O·X·빈칸 6문항, 바로 해설, '근거 찾기'로 근거 문단 표시
- **결과:** 영역별 결과(사실 확인·낱말·추론·적용·중심 생각·비판), 다시 보기 노트, 共 도장, 나의 共감 한 줄
- **선생님 도구:** 학습지 인쇄(정답 없음), 학습지 글 복사(정답 포함), 지난 호 보기

## 폴더 구조

```
index.html          화면 (글 내용은 들어 있지 않아요)
favicon.svg
data/index.json     주 목록 (최신 주가 맨 앞)
data/2026-W47.json  주별 글 5편과 문제
tools/validate.mjs  데이터 검사기
CONTENT_GUIDE.md    글쓰기·문제 만들기 지침
```

## 매주 새 글이 올라가는 방식

매주 일요일 저녁, Claude 예약 작업이 `CONTENT_GUIDE.md`에 따라 다음 주 글 5편을 쓰고, 사실을 확인하고,
`node tools/validate.mjs` 검사를 통과하면 이 저장소에 올려요. GitHub Pages가 몇 분 안에 사이트를 새로 만들어요.

## 글을 직접 고치려면

1. GitHub에서 `data/` 안의 주 파일(예: `2026-W47.json`)을 열고 연필 아이콘으로 고쳐요.
2. 따옴표와 쉼표가 빠지지 않게 조심해요. 저장(Commit changes)하면 몇 분 뒤 사이트에 반영돼요.
3. 컴퓨터에서 고쳤다면 `node tools/validate.mjs`로 검사해 보세요.

## 내 컴퓨터에서 미리 보기

글을 파일로 불러오기 때문에 `index.html`을 바로 더블클릭하면 열리지 않아요. 이 폴더에서 아래처럼 실행한 뒤 `http://localhost:8000`을 여세요.

```
python3 -m http.server 8000
```

## 기록 저장

학생이 푼 기록, 밑줄, 나의 共감 한 줄은 그 학생 기기의 브라우저(localStorage)에만 저장돼요. 서버로 보내지 않아요.
